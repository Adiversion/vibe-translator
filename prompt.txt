Har alag style, rant ya story ke liye baar-baar `worker.js` ko update karne ki bilkul zaroorat nahi hai.

Aapko sirf **ek baar** `worker.js` update karna hai, aur uska technical reason yeh hai:

---

### 1. Aapka Architecture Kaise Kaam Karta Hai?

Aapke extension ka flow aisa hai:

$$\text{Browser (Reddit)} \xrightarrow[\text{Only Text + Target Lang}]{\text{vibe-inject.js} \rightarrow \text{vibe-bridge.js}} \mathbf{\text{Cloudflare Worker}} \xrightarrow[\text{SYSTEM\_PROMPT + Config}]{\text{Calls Gemini API}} \text{Google LLM}$$

* `vibe-bridge.js` backend ko sirf yeh bhejta hai: `{ text: "...", targetLanguage: "hindi" }`.


* `vibe-bridge.js` ke andar likha hua `SYSTEM_PROMPT` aur `temperature` proxy request mein backend ko jaata hi nahi hai.


* **Asli System Prompt aur Temperature `worker.js` ke andar hardcoded hai.**
* Abhi aapke `worker.js` mein **purana prompt** aur `temperature: 0.7` chal raha hai, jo har story ko standard "polite narrator" mode mein bhej deta hai.

---

### 2. Kya Har Nayi Story/Style Ke Liye Worker Badlna Padega?

**Bilkul Nahi.**

Aapko har Reddit post ya har nayi kahani ke liye code nahi badalna hai. Jab aap `worker.js` ke system prompt mein ek generalized cognitive framework daal dete hain:

* **Pragmatic Slang Conversion:** Kisi bhi bhasha ke slang ko target language ke native slang mein badalna.
* **Cynical Venting Directive:** Internet rants ko bedtime story ("ek ladki hoti hai") ki tarah na bolkar group-chat banter ("ek ladki hai... laundon ko text karti hai") banana.
* **Low Temperature (0.35 - 0.4):** Polite defaults ko block karke direct street tone lock karna.

Yeh rules **generalize** ho jaate hain. Iske baad chahe:

1. Road rage ho (gaadi/accident),
2. Dating app scam expose ho,
3. Office/boss ka corporate rant ho, ya
4. College/hostel ka jhagda ho,

Model bina kisi naye update ke khud context pehchan kar us exact street register mein translate karega.

---

### 3. Permanent Solution: Prompt Ko Extension Se Pass Karein (Optional)

Agar aap future mein Cloudflare Worker ko touch hi nahi karna chahte, toh `vibe-bridge.js` aur `worker.js` ko aise sync kar sakte hain ki `vibe-bridge.js` prompt ko body ke sath bhej de:

```javascript
// vibe-bridge.js mein:
body: JSON.stringify({
  text: e.text,
  targetLanguage: langKey,
  targetDesc,
  systemInstruction: SYSTEM_PROMPT // <-- Extension hi rules bhejega
})

```

Aur Worker bas us `systemInstruction` ko forward kar dega. Isse jab bhi aap extension mein prompt refine karenge, Worker bina redeploy kiye automatically naye rules follow karega.
